# prose-tells

A working list of the things that make a paragraph read as machine-written, kept by one
person who edits a lot of drafts and got tired of explaining the same notes.

No package, no install. Read `RULES.md` and take what is useful.

Issues and pull requests welcome. I do not accept rules without an example of the tell in
the wild; a rule nobody can point at is a superstition.

There is no LICENSE file in this repository and that is not an oversight — I have not
decided what I want yet. Ask me if you need one.
